# Dr. Maya Reynolds, PsyD - Therapist Portfolio

A design-forward, custom homepage built for a fictional licensed clinical psychologist, designed as a practical assignment for the **Grow My Therapy** Front-End Developer Internship.

## Project Overview

This project showcases front-end development, UI/UX aesthetics, and highly-targeted website copy. The goal was to take an existing therapy practice template and elevate it to feel incredibly warm, human, and modern—without changing the core features.

### Key Features
- **Design Transformation:** Upgraded the color suite to an earthy, grounding palette (warm parchments and deep forest greens) rather than the standard clinical whites and blues.
- **Strategic Copywriting:** SEO-optimized headings (`<h1>`, `<h2>`) and personalized subtext drawn directly from Dr. Maya Reynolds' profile context (high achievers, burnout, CBT/EMDR).
- **Responsive Layout:** A highly intentional geometric hero section and robust CSS-Grid image selections.
- **Custom Section:** Successfully built and injected an entirely new `"A Calm Space for Healing"` section detailing her in-office aesthetic and telehealth capabilities.

## Tech Stack
* HTML5 (Semantic Markup)
* CSS3 (Custom Variables, Flexbox, CSS Grid, Fluid Typography)
* Vanilla JavaScript (Scroll Animations)
* Google Fonts (Outfit & Inter)
